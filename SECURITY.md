# Security policy

Skill Buddy is an early-stage open-source prototype, not a certified child-safety product or secure multi-account system.

## Reporting a vulnerability
Please do not publish exploitable details, real child data, profile backups, or API credentials in a public issue. Use GitHub's private vulnerability reporting feature if enabled for this repository; otherwise contact the repository owner privately and include a concise description, impact, and reproduction steps.

## Scope and current limitations
- Local profiles are not protected accounts and may be accessible to anyone using the same browser/device.
- Backup files can contain personal progress information; store them carefully.
- Optional AI features can transmit prompt data to a third-party provider.
- Security review and end-to-end tests are still needed before production use with children.

Please do not use real identifying information when reporting issues.
