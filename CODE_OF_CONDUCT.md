# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community for everyone, regardless of age, background, identity, experience, or point of view.

Examples of unacceptable behaviour include harassment, insults, intimidation, publishing private information, and deliberately disruptive conduct.

Project maintainers are responsible for clarifying standards and responding fairly to reports. If you experience or witness unacceptable behaviour, contact the project maintainers through the repository's private reporting channel. Please do not publish personal or child-related information in a public issue.

This project adopts the spirit and core expectations of the Contributor Covenant, version 2.1. See <https://www.contributor-covenant.org/version/2/1/code_of_conduct/> for the full reference text.
